# Artificial Intelligence – Semester Assignment 1

This repository contains the implementation of the first semester assignment for the Artificial Intelligence course.

The assignment focuses on uninformed search techniques, problem modeling, and search algorithms.

## Problems
1. **Social Golfers Problem** – DFS with Backtracking
2. **Sudoku Solver** – BFS with Backtracking
3. **Latin Square** – IDDFS with Backtracking
4. **Search Trees** – State-space exploration

## Technologies
- Python
- Git & GitHub
